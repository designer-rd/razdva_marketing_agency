# Анализ локаций

Назначение документа: сравнить стартовые и альтернативные районы Алматы для bar/club проекта.

Статус: ожидает исследования / заполнения.

## Будущие разделы

- методология оценки;
- Абылай хана / Жамбыла;
- Бухар Жырау / Космонавтов;
- дополнительные районы;
- сравнительная таблица;
- итоговый рейтинг.

## Первичные гипотезы для проверки

| Локация | Статус |
|---|---|
| Абылай хана / Жамбыла | Требует исследования |
| Бухар Жырау / Космонавтов | Требует исследования |
| Другие районы Алматы | Требует поиска и сравнения |

## Что проверять по каждой локации

- аудитория;
- вечерний / ночной трафик;
- конкуренты рядом;
- доступность на автомобиле;
- парковка;
- такси / drop-off;
- ограничения по шуму и режиму работы;
- арендная ставка;
- техническое состояние помещений.
