# Подготовка бизнес-плана

Рабочий документ перед созданием бизнес-плана по ювелирному бренду с лабораторными бриллиантами.

Цель: сначала согласовать структуру, собрать недостающие цифры и только потом писать бизнес-план и презентацию.

## 1. Текущий статус проекта

Проект пока находится на стадии идеи/оценки.

Уже есть:

- рыночный анализ;
- клиентская выжимка;
- список данных для уточнения;
- тезисная презентация для обсуждения;
- финансовая модель premium boutique/showroom;
- анализ рынка Алматы и целевой аудитории.

Главный вывод текущей аналитики:

> Заходить можно только через проверку спроса и экономики. Если запускать сразу с инвестициями 500 млн тг и премиальным шоурумом, проект становится капиталоемким premium retail запуском с высокой точкой безубыточности.

## 2. Что уже известно

### Факты / вводные клиента

| Блок | Что известно |
|---|---|
| Ниша | ювелирные изделия с лабораторными бриллиантами |
| География | Казахстан, старт логично рассматривать через Алматы |
| Дальше | возможно СНГ |
| Продукт | золото + лабораторные бриллианты |
| Формат | готовые изделия + изделия на заказ |
| Категории | кольца, серьги, подвески, браслеты, помолвочные/свадебные изделия |
| Средний чек | 400-500 тыс. тг по первичной вводной |
| Новый сценарий | запуск через premium boutique/showroom |
| Инвестиции в premium-сценарии | 500 млн тг |
| Товарный запас | около 150 млн тг |
| Маржа | 40% по вводной |
| Валовая прибыль с продажи при чеке 500k | 200 тыс. тг |
| Локация | premium-район Алматы, ориентиры Esentai / Villa dei Fiori |
| Аренда | 7-15 млн тг/мес |
| Маркетинг | 120 млн тг/год, около 10 млн тг/мес |

### Уже принятые аналитические выводы

- Алматы подходит лучше других городов Казахстана для premium jewelry, но рынок узкий.
- Lab-grown нужно объяснять: это не фианит, не муассанит и не природный бриллиант.
- Для высокого чека нужны сертификаты, проба, гарантия, консультация и доверие.
- Офлайн может быть инструментом доверия, но не должен быть единственным источником продаж.
- При чеке 500k и марже 40% большой бутик может требовать 150-250 продаж/мес для безубыточности.
- Для возврата 500 млн тг за 3 года может потребоваться 220-320 продаж/мес.
- Более устойчивая модель: premium private showroom по записи + bridal/custom + ограниченная витрина.

## 3. Главная развилка бизнес-плана

Бизнес-план должен сравнить два сценария.

### Сценарий A. Осторожный MVP

Формат:

- 3-5 физических образцов;
- 10-15 hero-моделей в каталоге;
- Instagram/WhatsApp;
- сайт/каталог;
- предзаказы;
- минимальный склад.

Задача:

- проверить спрос;
- проверить доверие к lab-grown;
- посчитать себестоимость;
- протестировать каналы;
- не заморозить капитал.

### Сценарий B. Premium showroom / boutique

Формат:

- инвестиции около 500 млн тг;
- товарный запас около 150 млн тг;
- помещение 120-200 м²;
- аренда 7-15 млн тг/мес;
- premium локация;
- команда продаж;
- высокий сервис;
- готовые изделия + custom/pre-order.

Задача:

- сразу строить premium jewelry brand;
- создать доверие через физическое пространство;
- продавать high-ticket изделия;
- увеличить средний чек через bridal/custom.

Риск:

- высокая точка безубыточности;
- большие постоянные расходы;
- риск неправильного товарного запаса;
- необходимость 150-250 продаж/мес для нуля.

## 4. Рекомендуемая структура бизнес-плана

### 1. Executive Summary

Что должно быть:

- короткий вердикт;
- какой сценарий рассматривается;
- сколько нужно инвестиций;
- какая главная финансовая логика;
- где точка безубыточности;
- главные риски;
- условия, при которых стоит запускать.

Ключевой вопрос:

> Можно ли построить модель, где средний чек, маржа и объем продаж покрывают постоянные расходы premium showroom?

### 2. Концепция бренда

Что раскрыть:

- что за бренд;
- почему lab-grown;
- чем отличается от классической ювелирки;
- чем отличается от фианита/муассанита;
- какой уровень: accessible luxury, premium, bridal/custom;
- почему Алматы.

Что нужно от клиента:

- название;
- видение бренда;
- ценности;
- визуальные референсы;
- уровень премиальности.

### 3. Продуктовая стратегия

Что раскрыть:

- категории изделий;
- металлы;
- камни;
- сертификаты;
- готовые изделия vs custom;
- стартовая коллекция;
- hero-SKU;
- роль bridal.

Что нужно посчитать:

- себестоимость каждой модели;
- розничную цену;
- маржу;
- срок производства;
- риск брака/возврата;
- минимальную партию.

### 4. Рынок и целевая аудитория

Что использовать:

- файл `07. Рынок Алматы и целевая аудитория.md`;
- сегменты: помолвка, подарок, self-purchase, bridal/wedding, premium lifestyle;
- рабочую оценку аудитории Алматы.

Что нужно проверить:

- готовность платить 400-500k;
- готовность ждать custom;
- роль примерки;
- понимание lab-grown;
- доверие к новому бренду.

### 5. Конкуренты и позиционирование

Что использовать:

- классические ювелиры;
- Sokolov/Pandora;
- локальные бутики;
- Instagram-мастера;
- прямые lab-grown конкуренты;
- маркетплейсы.

Что нужно добрать:

- 20-30 актуальных конкурентов;
- цены по категориям;
- наличие lab-grown;
- формат продаж;
- УТП;
- уровень визуала;
- сертификаты;
- шоурум/офлайн.

### 6. Бизнес-модель

Что сравнить:

- MVP;
- гибрид;
- private showroom;
- полноценный boutique/retail.

Для каждого:

- инвестиции;
- расходы;
- маржа;
- риски;
- точка безубыточности;
- условия перехода на следующий уровень.

### 7. Операционная модель

Что раскрыть:

- поставщики в Китае;
- контроль качества;
- логистика;
- таможня;
- пробирный контроль;
- сертификаты;
- склад;
- упаковка;
- гарантия;
- возвраты;
- ремонт;
- безопасность;
- персонал.

Без этого бизнес-план будет неполным.

### 8. Go-to-market

Каналы:

- Instagram/Reels;
- TikTok;
- WhatsApp;
- сайт/каталог;
- Google;
- Kaspi;
- блогеры;
- wedding partners;
- pop-up/private events;
- рекомендации.

Для каждого канала:

- роль;
- бюджет;
- KPI;
- риск;
- что считать.

### 9. Финансовая модель

Обязательные блоки:

- инвестиции;
- распределение бюджета;
- товарный запас;
- себестоимость;
- средний чек;
- маржа;
- валовая прибыль;
- постоянные расходы;
- переменные расходы;
- P&L;
- cash flow;
- точка безубыточности;
- окупаемость;
- сценарии продаж.

### 10. Риски

Группы:

- спрос;
- доверие;
- поставщик;
- качество;
- legal;
- пробирный контроль;
- склад;
- CAC;
- аренда;
- персонал;
- кассовый разрыв;
- курс валют.

Для каждого:

- вероятность;
- ущерб;
- как снизить;
- какой early warning signal.

### 11. План запуска

Разделить:

- 0-30 дней: проверка данных и подготовка;
- 31-60 дней: образцы, контент, тест заявок;
- 61-90 дней: первые продажи/предзаказы;
- 3-6 месяцев: showroom/pop-up;
- 6-12 месяцев: масштабирование.

### 12. Инвестиционное решение

В конце бизнес-плана должно быть:

- запускать / не запускать / запускать при условиях;
- какой формат выбрать;
- сколько инвестировать на первом этапе;
- какие метрики должны быть достигнуты;
- когда остановиться;
- когда масштабировать.

## 6. Критичные цифры, которых не хватает

Без этих данных бизнес-план будет моделью, а не инвестиционным документом.

### Продукт и себестоимость

- SKU стартовой коллекции.
- Фото/референс каждого SKU.
- Металл: 585/750, вес в граммах.
- Камень: ct, форма, цвет, чистота, сертификат.
- Себестоимость по каждому SKU.
- Стоимость производства.
- Стоимость упаковки.
- Стоимость сертификата.
- Минимальная партия.
- Срок производства.
- Срок доставки.

### Поставщик

- Страна/город.
- Производитель или посредник.
- Условия оплаты.

- Условия возврата.

- Документы на золото.

### Showroom / бутик

- Ремонт.
- Мебель.
- Витрины.
- Сейфы.
- Охрана.
- Камеры.

- Коммунальные.
- Срок договора аренды.

### Команда

- Управляющий.
- Продавцы-консультанты.
- Геммолог/эксперт или обученный консультант.
- Контент/маркетинг.
- Бухгалтерия.
- Охрана.
- ФОТ.
- Мотивация продавцов.

### Маркетинг и продажи

- Бюджет по каналам.
- План блогеров.
- Google/таргет.
- Контент-продакшн.

- Сайт/каталог.

## 7. Что нужно запросить у клиента в первую очередь

Минимальный пакет для продолжения:

1. Бюджет: 500 млн тг подтвержден или это ориентир?
2. Как планируется распределить 500 млн тг?
3. Есть ли выбранная локация и условия аренды?
4. Есть ли поставщик в Китае?
5. Есть ли прайс/quotes от поставщика?
6. Есть ли 10-20 конкретных моделей для старта?
7. Есть ли данные по золоту, весу, камням, сертификатам?
8. Какие документы поставщик дает?
9. Как планируется проходить пробирный контроль?
10. Кто будет управлять бизнесом каждый день?
11. Какой формат точки: бутик с потоком или private showroom по записи?
12. Какой целевой средний чек: 500k, 800k, 1.2m+?
13. Какая желаемая окупаемость: 2 года, 3 года, 5 лет?
14. Какой допустимый ежемесячный минус на старте?
15. Сколько месяцев runway заложено?

## 8. Рекомендуемый порядок дальнейшей работы

### Шаг 1. Подтвердить вводные

Собрать ответы по блоку `Что нужно запросить у клиента в первую очередь`.

### Шаг 2. Собрать SKU-экономику

Для 10-20 моделей:

- себестоимость;
- цена продажи;
- маржа;
- срок изготовления;
- размер партии;
- риск брака;
- retail value склада.

### Шаг 3. Собрать operating budget

По premium showroom:

- аренда;
- ремонт;
- мебель;
- команда;
- безопасность;
- маркетинг;
- контент;
- CRM;
- legal;
- резерв.

### Шаг 4. Собрать финансовую модель

Сценарии:

- conservative;
- base;
- aggressive;
- premium showroom stress-test.

### Шаг 5. Написать бизнес-план

Только после цифр.

### Шаг 6. Сделать презентацию

Презентация должна быть короче бизнес-плана:

- 12-15 слайдов;
- decision-oriented;
- цифры;
- риски;
- сценарии;
- решение.

## 10. Рабочий вердикт до получения новых данных

Пока нельзя писать финальный бизнес-план как “проект готов к запуску”.

Текущий статус:

- идея интересная;
- рынок в Алматы есть;
- аудитория узкая;
- категория требует объяснения;
- premium showroom может усилить доверие;
- при чеке 500k и марже 40% большой бутик имеет тяжелую экономику;
- нужна точная SKU-экономика и условия аренды;
- без этого любые выводы по окупаемости будут слишком грубыми.

Следующее действие:

> Запросить у клиента данные по поставщику, SKU, себестоимости, аренде, команде и распределению инвестиций. После этого собрать финансовую модель и только потом писать бизнес-план.
