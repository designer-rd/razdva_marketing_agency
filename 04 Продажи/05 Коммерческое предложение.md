# Коммерческое предложение

Коммерческое предложение RazDva — это не прайс и не презентация “кто мы”.

Это документ, который переводит диагностику в решение: что увидели, где бизнес теряет заявки, что нужно внедрить, сколько это стоит и какой следующий шаг.

## 1. Цель КП

- Зафиксировать проблему.
- Показать логику решения.
- Снять риск покупки.
- Объяснить ценность стоимости.
- Довести клиента до решения.

## 2. Когда делать КП

Делать КП, если:

- проведен экспресс-аудит или полный аудит;
- клиент понимает проблему;
- есть конкретный запрос;
- понятны сроки и объем;
- есть шанс на оплату.

Не делать КП, если:

- клиент просто “сравнивает цены”;
- нет понимания задачи;
- нет доступа к ключевым материалам;
- клиент хочет гарантию результата;
- проект не подходит агентству.

## 3. Обязательная структура КП

### 1. Вводный блок

Коротко:

- клиент;
- ниша;
- задача;
- контекст;
- что смотрели.

### 2. Что увидели в аудите

3-5 наблюдений:

- без резкой критики;
- только конкретика;
- привязка к заявкам, доверию, конверсии или росту.

### 3. Где теряются заявки/доверие

Показать путь:

- человек увидел;
- заинтересовался;
- проверил;
- засомневался;
- не написал/не купил.

### 4. Что предлагаем внедрить

Не “сделать сайт”, а:

- усилить оффер;
- собрать страницу доверия;
- настроить путь до заявки;
- упаковать UGC/отзывы;
- подготовить креативы;
- внедрить аналитику;
- собрать WhatsApp-воронку.

### 5. План работ

Разбить по этапам:

- неделя 1;
- неделя 2;
- неделя 3;
- запуск;
- тестирование;
- отчет.

### 6. Сроки

Указать:

- старт;
- длительность;
- контрольные точки;
- что зависит от клиента.

### 7. Стоимость

Стоимость должна быть связана с объемом, а не просто стоять в конце.

Формат:

- вариант 1: быстрые внедрения;
- вариант 2: основное внедрение;
- вариант 3: сопровождение/расширение.

### 8. Что клиент получит

Формулировать результат в артефактах:

- отчет;
- структура лендинга;
- готовая страница;
- креативы;
- таблица учета;
- WhatsApp-скрипт;
- план тестов;
- dashboard/таблица.

### 9. Что нужно от клиента

- доступы;
- материалы;
- фото/видео;
- данные по продажам;
- обратная связь;
- ответственное лицо;
- сроки согласования.

### 10. Следующий шаг

Всегда конкретный:

- согласовать вариант;
- внести предоплату;
- назначить старт;
- передать материалы;
- провести kick-off.

## 4. Что должно вызвать желание купить

КП должно показывать:

- проблема понятна;
- решение логичное;
- работы ограничены и управляемы;
- есть порядок действий;
- есть быстрый первый результат;
- есть контроль качества;
- цена связана с ценностью;
- клиент не остается один с рекомендациями.

## 5. Ошибки, которые нельзя допускать

- Делать КП без диагностики.
- Начинать с цены.
- Продавать все подряд.
- Называть услуги без связи с проблемой.
- Обещать гарантированный рост.
- Писать длинную теорию.
- Не указывать, что входит и не входит.
- Не фиксировать следующий шаг.
- Не указывать, что нужно от клиента.
- Прятать риски.

## 6. Форматы КП

### Короткое КП для WhatsApp

Использовать после экспресс-аудита.

Структура:

1. Короткий вывод.
2. Что можно внедрить.
3. Срок.
4. Стоимость.
5. Что получите.
6. Следующий шаг.

Пример:

“По разбору видно, что основная точка роста сейчас — не просто трафик, а доверие и путь до заявки. Можно начать с быстрых внедрений: оффер, структура профиля/лендинга, блоки доверия, CTA и базовый путь в WhatsApp. Срок — 5-7 дней. Стоимость — X. На выходе будет готовая упаковка первого касания и понятный путь клиента до заявки.”

### Подробное КП в PDF/презентации

Использовать для:

- высокого чека;
- сложной ниши;
- нескольких вариантов;
- внедрения;
- сопровождения.

### HTML КП-лендинг

Использовать для заинтересованных клиентов, когда нужно дать ссылку на аккуратную публичную презентацию.

Правила:

- внутренние заметки не публиковать;
- спорные гипотезы не выдавать как факты;
- личные данные не публиковать;
- структура: проблема -> аудит -> решения -> план -> стоимость -> следующий шаг.

## 7. Контроль качества КП

Перед отправкой проверить:

- [ ] Есть главный вывод.
- [ ] Есть связь с аудитом.
- [ ] Есть 2-3 варианта решения или один четкий вариант.
- [ ] Понятно, что входит.
- [ ] Понятно, что не входит.
- [ ] Есть сроки.
- [ ] Есть стоимость.
- [ ] Есть следующий шаг.
- [ ] Нет обещаний гарантированного результата.
- [ ] Нет внутренних черновиков.
