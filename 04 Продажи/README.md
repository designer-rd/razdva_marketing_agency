# README — система продаж RazDva

Этот раздел описывает, как отдел продаж RazDva ведет клиента от первого интереса до внедрения, результата, кейса и повторных продаж.

RazDva продает не отдельные услуги, а систему:

анализ -> стратегия -> внедрение -> тестирование -> рост.

## 1. Структура раздела

| Файл | За что отвечает |
|---|---|
| `00 Путь клиента.md` | Главная карта пути клиента от контента до повторных продаж. |
| `01 Воронка продаж.md` | Внутренняя воронка, KPI, ошибки и критерии перехода. |
| `02 Первый контакт.md` | Как писать и говорить с новым клиентом без давления. |
| `03 Экспресс-аудит.md` | Стандарт главного входного продукта агентства. |
| `04 Полный аудит.md` | Стандарт платного системного анализа бизнеса. |
| `05 Коммерческое предложение.md` | Как оформлять предложение после диагностики. |
| `06 Внедрение.md` | Как переводить стратегию в реальные изменения. |
| `07 Сопровождение.md` | Как вести клиента на долгосрочной работе. |

## 2. В каком порядке использовать

1. Прочитать `00 Путь клиента.md`.
2. Изучить `01 Воронка продаж.md`.
3. Использовать `02 Первый контакт.md` при новом диалоге.
4. Делать экспресс-аудит по `03 Экспресс-аудит.md`.
5. Если проблема системная — продавать полный аудит по `04 Полный аудит.md`.
6. После аудита оформлять предложение по `05 Коммерческое предложение.md`.
7. После оплаты передавать проект во внедрение по `06 Внедрение.md`.
8. После результата предлагать сопровождение по `07 Сопровождение.md`.
9. После результата/доверия запускать повторные продажи по `08 Повторные продажи.md`.

## 3. Как работает новый сотрудник

### День 1. Понимание агентства

Прочитать:

- `01 Позиционирование/Кто мы.md`;
- `01 Позиционирование/Оффер агентства.md`;
- `02 Продукты и услуги/Цены и пакеты.md`;
- `04 Продажи/00 Путь клиента.md`.

Задача:

понять, что RazDva — не веб-студия, не SMM и не рекламное агентство. RazDva — маркетинговое агентство с внедрением.

### День 2. Воронка и контакт

Прочитать:

- `01 Воронка продаж.md`;
- `02 Первый контакт.md`;
- `Скрипт первого касания.md`.

Задача:

научиться открывать диалог без давления и фиксировать следующий шаг.

### День 3. Аудиты

Прочитать:

- `03 Экспресс-аудит.md`;
- `04 Полный аудит.md`;
- `03 Аудит бизнеса/Вопросы для экспресс-аудита.md`;
- `03 Аудит бизнеса/Вопросы для полного аудита.md`;
- `03 Аудит бизнеса/Чеклист экспресс-аудита.md`.

Задача:

понять разницу между бесплатным входным разбором и платной глубокой диагностикой.

### День 4. КП и внедрение

Прочитать:

- `05 Коммерческое предложение.md`;
- `Шаблон коммерческого предложения.md`;
- `06 Внедрение.md`.

Задача:

научиться переводить выводы аудита в конкретный объем работ.

### День 5. Сопровождение и LTV

Прочитать:

- `07 Сопровождение.md`;
- `08 Повторные продажи.md`;
- `07 Клиентские проекты/CRM.md`.

Задача:

понять, как не терять клиента после первого проекта.

## 4. Единый путь клиента

Контент -> интерес -> сообщение -> созвон -> экспресс-аудит -> полный аудит -> презентация -> стратегия -> внедрение -> результат -> кейс -> повторные продажи.

Любой сотрудник должен уметь ответить:

- на каком этапе клиент сейчас;
- какая цель этапа;
- что должен получить клиент;
- какой следующий шаг;
- какой KPI показывает успех;
- что фиксировать в CRM.

## 5. Правила продаж RazDva

- Не продавать до диагностики.
- Не обещать гарантированный рост.
- Не говорить “вам нужен сайт”, пока не понятен путь клиента.
- Не делать SMM ради SMM.
- Не отправлять прайс без контекста.
- Не отдавать полный аудит бесплатно.
- Не начинать проект без зафиксированного объема.
- Не терять клиента после сдачи.

## 6. Минимальный стандарт CRM

Для каждого клиента фиксировать:

- клиент;
- ниша;
- статус;
- следующий шаг;
- дата следующего контакта;
- потенциал;
- услуга;
- ссылка на карточку;
- ссылка на КП.

## 7. Главный стандарт мышления

В каждом диалоге искать не “какую услугу продать”, а:

1. Где бизнес теряет клиента?
2. Почему это происходит?
3. Что нужно проверить?
4. Что можно быстро улучшить?
5. Что требует полного анализа?
6. Что можно внедрить руками?
7. Как измерить результат?
