# Сопровождение

Сопровождение — долгосрочная работа после аудита или первого внедрения.

Цель сопровождения: регулярно анализировать маркетинг клиента, запускать новые гипотезы, улучшать путь клиента и поддерживать рост.

## 1. Когда предлагать сопровождение

Предлагать, если:

- клиент уже прошел аудит;
- есть внедренные изменения;
- есть регулярные заявки/трафик;
- нужно тестировать каналы;
- бизнес растет или хочет расти;
- у клиента нет внутреннего маркетинг-директора;
- есть бюджет на системную работу.

Не предлагать, если:

- нет продукта;
- нет ресурсов на внедрение;
- клиент не дает данные;
- клиент ждет гарантированный результат;
- нет ответственного со стороны клиента.

## 2. Что входит в сопровождение

Базовые блоки:

- ежемесячный анализ;
- план работ;
- гипотезы роста;
- контроль внедрения;
- улучшение упаковки;
- креативы;
- сайт/лендинг/воронка;
- аналитика;
- подрядчики;
- отчет.

## 3. Ежемесячный цикл

### Неделя 1. Анализ

Смотреть:

- заявки;
- продажи;
- каналы;
- конверсию;
- рекламу;
- сайт;
- Instagram;
- WhatsApp;
- отзывы;
- конкурентов.

Выход:

- список проблем;
- список гипотез;
- приоритеты месяца.

### Неделя 2. Производство

Делать:

- тексты;
- креативы;
- лендинг-блоки;
- сценарии;
- таблицы;
- настройки;
- материалы для запуска.

Выход:

- готовые артефакты.

### Неделя 3. Запуск

Запускать:

- креативы;
- новые CTA;
- страницу;
- оффер;
- рекламные тесты;
- партнерские гипотезы;
- WhatsApp-сценарии.

Выход:

- активные тесты.

### Неделя 4. Выводы

Смотреть:

- что сработало;
- что не сработало;
- что масштабировать;
- что остановить;
- что изменить.

Выход:

- отчет;
- план следующего месяца.

## 4. KPI сопровождения

Выбирать под проект:

- количество заявок;
- стоимость заявки;
- качество лидов;
- конверсия в продажу;
- средний чек;
- ROMI;
- выручка;
- валовая прибыль;
- скорость обработки заявки;
- конверсия лендинга;
- клики WhatsApp;
- сохранения/ответы в Instagram;
- количество гипотез;
- скорость внедрения.

## 5. Формат работы

Обязательные элементы:

- ежемесячный план;
- weekly check-in;
- единая таблица задач;
- статус по каждому направлению;
- отчет в конце месяца;
- список решений на следующий месяц.

## 6. Что клиент должен давать

- данные по заявкам;
- данные по продажам;
- доступы;
- материалы;
- обратную связь;
- ответственное лицо;
- решения по согласованию;
- информацию о продукте/ценах/наличии.

Без данных сопровождение превращается в “ведение маркетинга на ощущениях”, что запрещено.

## 7. Что нельзя делать на сопровождении

- Делать контент без связи с продажами.
- Не смотреть цифры.
- Каждый месяц начинать с нуля.
- Игнорировать CRM/заявки.
- Тестировать без гипотез.
- Масштабировать то, что не доказано.
- Обещать рост без контроля продукта и продаж.

## 8. Итог сопровождения

Каждый месяц должен завершаться ответами:

1. Что сделали?
2. Что изменилось?
3. Какие цифры получили?
4. Какие выводы?
5. Что делаем дальше?
