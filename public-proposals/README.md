# Public Proposals

Здесь будут храниться публичные HTML-страницы коммерческих предложений.

Каждая папка внутри — отдельное КП для клиента:

- `public-proposals/client-slug/index.html`

Внутренние заметки нельзя класть в `public-proposals`.

Страницы должны содержать только то, что можно отправлять клиенту: понятный контекст, выводы аудита, предложение, сроки, стоимость и следующий шаг.
