# RazDva Marketing Agency

Этот vault — рабочая база для трансформации RazDva из студии сайтов и дизайна в маркетинговое агентство с внедрением.

RazDva помогает бизнесу расти через анализ, упаковку, воронки, сайты, рекламу, креативы, AI-инструменты и автоматизацию. Главный принцип: не просто давать рекомендации, а находить слабые места в маркетинге и внедрять решения руками.

## Текущий фокус

- Первый рынок: Алматы.
- Первая ниша: образование, школы, курсы, детские центры, языковые школы, наставники, студии.
- Первый входной продукт: бесплатный экспресс-аудит маркетинговой упаковки и пути клиента.
- Методология: анализ -> стратегия -> внедрение -> тестирование -> рост.

## Как пользоваться

1. Начинать день с [[00 Панель управления/Главная]].
2. Для нового лида создавать карточку по шаблону [[07 Клиентские проекты/_Шаблон клиента]].
3. Перед аудитом открывать [[03 Аудит бизнеса/Чеклист экспресс-аудита]].
4. Для первого контакта использовать [[04 Продажи/Скрипт первого касания]].
5. Все идеи, которые пока не стали продуктом или процессом, складывать в [[08 База знаний]].
